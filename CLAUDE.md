# CLAUDE.md — правила работы в этом репозитории

## Правило по ссылкам (ОБЯЗАТЕЛЬНО)

Когда я заканчиваю задачу, я **всегда** отдаю пользователю ссылку:

- **Пока идёт разработка / промежуточный результат** → даю ссылку **внутри Claude**
  (Artifact-превью на claude.ai или ссылка на сессию), чтобы пользователь мог
  сразу посмотреть, не выходя из чата.
- **После того как пользователь подтвердил, что всё готово** → даю ссылку на
  **GitHub Pages** этого репозитория (задеплоенную страницу).

Никогда не завершаю ответ без ссылки, если результатом является что-то,
что можно посмотреть.

## Контекст проекта

- Основной артефакт в корне — `index.html` (может публиковаться через GitHub Pages).
- Подпроект `voice-studio/` — локальный инструмент озвучки видео одним AI-голосом
  (XTTS-v2 + Gradio), рассчитан на работу на CPU.
