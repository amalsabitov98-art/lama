# 🎛️ Voice Studio

Локальный инструмент для озвучки видео **одним консистентным AI-голосом**.

Идея простая: ты один раз добавляешь голос (короткий аудио-сэмпл), и дальше
все твои ролики звучат этим же тембром — сегодня, завтра, через месяц.
Отлично сочетается с генеративным видео (например, роликами из **Veo 3**):
видео генерируешь там, а стабильный голос кладёшь здесь.

Два режима:

| Режим | Что делает | Скорость на CPU |
|---|---|---|
| 🎬 **Говорящий в кадре** | Озвучка + подгонка губ под речь (липсинк, Wav2Lip) | Медленно (минуты) |
| 🔊 **Закадровая озвучка** | Голос поверх нарезки/б-ролла, без липсинка | Быстро |

Всё работает **локально**, без облака. Видеокарта NVIDIA не обязательна —
на обычном CPU всё тоже работает, просто медленнее.

## Требования

- **Python 3.9+**
- **ffmpeg** (системно):
  - macOS: `brew install ffmpeg`
  - Ubuntu/Debian: `sudo apt install ffmpeg`
- Опционально: **Wav2Lip** для липсинка (см. раздел «Липсинк» ниже)

## Установка

Проще всего — скриптом:

```bash
./install.sh
```

Или вручную:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

При первом синтезе речи автоматически докачается модель XTTS-v2 (~2 ГБ) —
это разовая операция, дальше она лежит в кэше.

## Липсинк (Wav2Lip) — опционально

Липсинк нужен только для режима «Говорящий в кадре». Это отдельный проект
([Wav2Lip](https://github.com/Rudrabha/Wav2Lip)) с большими весами, поэтому
он не вшит в Voice Studio и ставится отдельно:

1. Запусти `./install.sh` и согласись на установку Wav2Lip (или запусти
   `./install.sh --with-wav2lip`). Скрипт склонирует репозиторий в
   `third_party/Wav2Lip`.
2. Скачай веса `wav2lip_gan.pth` (ссылки — в README самого Wav2Lip) и положи
   их в `third_party/Wav2Lip/checkpoints/wav2lip_gan.pth`.

Важно знать:

- ⏳ **На CPU липсинк медленный** — грубо, несколько минут на каждые
  10–15 секунд видео. Длинные ролики лучше резать на куски.
- 🔊 Режим **«Закадровая озвучка» работает всегда и без Wav2Lip** — это
  быстрый вариант, если липсинк не нужен или не установлен.
- Если Wav2Lip не найден, режим «Говорящий в кадре» не упадёт: голос всё
  равно наложится, просто без подгонки губ (и интерфейс честно об этом скажет).

## Запуск

```bash
source .venv/bin/activate
python app.py
```

Откроется локальный веб-интерфейс (адрес появится в консоли,
обычно http://127.0.0.1:7860).

## Как пользоваться

1. **Добавь голос** (вкладка «🎙️ Голоса»): загрузи аудио с **5–30 секундами
   чистой речи** — без музыки, шума и других голосов. Чем чище сэмпл, тем
   лучше клон. Дай голосу имя.
2. **Выбери режим**: «Говорящий в кадре» (человек говорит на камеру) или
   «Закадровая озвучка» (голос поверх нарезки).
3. **Загрузи видео и напиши текст**, который нужно озвучить.
4. Жми **«Собрать»** и дождись результата — готовый mp4 появится в превью
   и сохранится в `data/output/`.

Идеи текстов для рилсов — в [prompt_templates.md](prompt_templates.md).

## Структура данных

```
data/voices/   — библиотека голосов (сэмплы + index.json)
data/output/   — готовые ролики и озвучки
third_party/Wav2Lip/  — липсинк (опционально)
```

## ⚖️ Этичное использование

Voice Studio — инструмент для **твоего** контента и **твоих** голосов
(или голосов, на использование которых у тебя есть явное согласие владельца).
Клонировать чужой голос без разрешения — незаконно и неэтично: не делай так.
Ты сам отвечаешь за то, что и чьим голосом озвучиваешь.
