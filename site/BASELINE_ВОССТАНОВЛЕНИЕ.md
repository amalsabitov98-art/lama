# Рабочая версия (точка восстановления)

Это снимок **рабочего** генератора ваучеров на момент, когда вёрстка PDF
совпала с эталоном. Если дальнейшие правки дизайна что-то сломают —
отсюда можно вернуть заведомо рабочий вариант.

## Что сохранено

- **`pdf.baseline.js`** — рабочая версия отрисовки PDF (копия `pdf.js`).
  Если `pdf.js` сломается: скопировать `pdf.baseline.js` → `pdf.js`.
- **`standalone.working.html`** — всё приложение в одном файле
  (форма + библиотеки + шрифты + логика). Открывается двойным кликом
  в браузере и работает офлайн. Это «аварийная копия»: даже если
  остальные файлы сломаются, этот открывается и работает.
- Git-тег **`baseline-working`** отмечает этот коммит целиком.

## Как восстановить

Вернуть только отрисовку PDF:

    cp site/pdf.baseline.js site/pdf.js

Вернуть всю папку сайта к рабочему состоянию:

    git checkout baseline-working -- site/

Просто открыть рабочую версию, ничего не восстанавливая:
двойной клик по `site/standalone.working.html`.
