# Watermark Cleaner

Локальное Windows-приложение для удаления ватермарка с собственных видео. Видео никуда не загружается.

## Первый запуск

1. Установите **Python 3.11 или новее** с [python.org](https://www.python.org/downloads/windows/). При установке включите пункт `Add Python to PATH`.
2. Дважды нажмите `install_and_start.bat`. Первый запуск скачает бесплатные компоненты и может занять несколько минут.
3. В дальнейшем запускайте приложение файлом `start.bat`.

## Использование

1. Нажмите **Открыть видео**.
2. Выберите на шкале кадр, где ватермарк хорошо заметен.
3. Закрасьте ватермарк левой кнопкой мыши. Правая кнопка стирает маску. Белый круг показывает точный охват кисти. Размер по умолчанию — **9 px**; его можно менять ползунком, кнопками `− / +` или колесом мыши над кадром.
4. Начните с режима **Соседние кадры — основной**: он пытается перенести настоящие детали из предыдущих и следующих кадров. Если фон почти не движется или детали под ватермарком нигде не видны, выберите **AI-текстура — медленно**: начиная с версии 0.3.0 он дорисовывает текстуру в полном разрешении кадра, без размытой заплатки. При первом AI-рендере приложение один раз скачает модель LaMa размером 92,6 МБ. **Локальный — быстро** подходит для простого фона и черновой проверки.
5. Нажмите **Удалить ватермарк** и выберите имя готового MP4-файла.

## Советы по качеству

- Закрашивайте весь логотип, включая полупрозрачные края. Параметр «Запас вокруг маски» автоматически расширяет область; по умолчанию используется аккуратный запас 1 px.
- Чем уже и точнее маска, тем меньше область, которую требуется восстанавливать.
- Сначала проверьте короткий фрагмент. Если края логотипа остались, увеличьте запас до 3–4 px.
- Качественный режим особенно полезен, когда камера или фон движутся. На полностью неподвижном кадре приложение использует локальное восстановление.
- Для минимального размытия оставьте «Радиус восстановления» равным 1 px. Повышать его стоит только для однотонного фона или крупного логотипа.
- AI-режим заметно медленнее обычного: на процессоре один кадр может занимать несколько секунд. На статичных сценах он переиспользует уже готовую заплатку, поэтому неподвижные ролики обрабатываются намного быстрее и без мерцания. Он создаёт правдоподобную текстуру вместо простого растягивания соседних пикселей, но не может восстановить точные данные, которых нет ни в одном кадре.
- Если после AI-режима под ватермарком всё же виден след, чуть увеличьте «Запас вокруг маски» (2–3 px): полупрозрачная кромка логотипа обычно шире, чем кажется.

## Ограничения первой версии

- Одна маска применяется ко всему ролику. Если ватермарк меняет положение внутри одного файла, такой ролик пока нужно разделить на фрагменты.
- Если ватермарк постоянно закрывает лицо, текст или другую уникальную деталь, точный оригинал восстановить невозможно — получится правдоподобная реконструкция.
- Обработка 4K-видео без мощного компьютера может занимать продолжительное время.
- AI-модель LaMa предоставляется OpenCV под лицензией Apache 2.0 и хранится локально в `%LOCALAPPDATA%\WatermarkCleaner\models`.

Приложение предназначено для обработки собственных видео и материалов, на изменение которых у пользователя есть право.
